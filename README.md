📌 Project Overview

This project is a Power BI dashboard based on a Data Professional Survey.

The dashboard explores important questions about people working in the data field, including:

👥 How many people participated in the survey?

💼 What job roles are represented?

💰 How does average salary vary by role?

💻 Which programming languages are most popular?

🌍 Which countries are represented?

😊 How satisfied are professionals with their salary and work/life balance?

🚪 How difficult is it to enter the data industry?

🎂 What is the average age of survey participants?

The goal is to practice the complete Power BI analysis workflow — from understanding data to building an interactive dashboard and communicating insights visually.

🎯 Project Objectives

Transform survey data into an easy-to-understand dashboard.

Analyze career and salary patterns across data-related roles.

Understand programming-language preferences.

Explore professional satisfaction.

Identify challenges faced when entering the data industry.

Build a clean and professional Power BI portfolio project.

🔍 Analysis Areas

1. 💼 Job Roles & Salary

The dashboard compares average salary across different job titles.

This helps identify how compensation differs between roles represented in the survey.

2. 💻 Programming Language Preferences

The Favorite Programming Language visual provides an overview of which programming languages are preferred by survey participants.

3. 🌍 Geographic Distribution

The country treemap provides a quick view of the geographic distribution of respondents.

4. 😊 Professional Satisfaction

Two gauge visuals examine satisfaction with:

Salary

Work/life balance

These metrics provide a simple view of how professionals feel about important parts of their current positions.

5. 🚀 Breaking Into Data

The dashboard also analyzes how difficult respondents felt it was to break into the data industry.

This can help aspiring analysts understand that entering the field may involve different levels of difficulty depending on individual experience.
